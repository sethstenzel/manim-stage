# Algorithm gallery (manim-stage educational helpers)

Four scenes, one per helper family: `Recursion` (call stack from a recorded trace), `BubblePass` (array, pointer, recorded steps), `Structures` (heap tree, linked list, weighted `Graph` with `tree_layout` and `label_edges`), `Protocol` (sequence diagram). See [`docs/kb/manim-stage/edu.md`](../../docs/kb/manim-stage/edu.md).

```bash
manim-stage studio gallery.py Recursion
manim -ql gallery.py BubblePass
```
